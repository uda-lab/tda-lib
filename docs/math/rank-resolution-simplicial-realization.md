# A simplicial realization of the degree-two rank witness

The module `RankResolutionDegreeTwo.finiteModule` was defined independently on
the finite grid `G = {0,1,2} × {0,1,2}`. Its support is the three-point L

```text
       c=(1,1)
      /       \
 a=(0,1)     b=(1,0)
```

with identity maps from `a` and `b` to `c`. This note records a literal
filtered-complex model for that module. For every field `k`, with no assumption
on its characteristic, the actual unreduced degree-one simplicial homology of
the filtration is naturally isomorphic to `finiteModule` on `G` and to
`RankResolutionDegreeTwo.realModule` on all of `ℝ²`.

## The actual filtered complex

Take the boundary of the tetrahedron on the ordered vertices `0,1,2,3`: its
faces are all 14 nonempty proper subsets of `Fin 4`, including all six edges
and four triangles, and it has no three-simplex. The grading is coordinatewise
monotone under face inclusion and is given literally by

| Faces | Grade |
| --- | --- |
| vertices `0,1,2,3`; edge `01` | `o=(0,0)` |
| edges `02,12` | `a=(0,1)` |
| edges `03,13` | `b=(1,0)` |
| edge `23`; triangles `023,123` | `c=(1,1)` |
| triangle `012` | `d=(0,2)` |
| triangle `013` | `e=(2,0)` |

The repeated grades are intentional. The two coordinate sets computed from
these actual face grades are both exactly `{0,1,2}`, so this is the same grid
used by the independently constructed finite module. No homology or
presentation certificate is supplied as input.

## Signed chains and the quotient

Use increasing vertex order for the existing signed deletion boundary. In the
ambient one-skeleton, let

```text
α = 01 − 02 + 12 = ∂012
β = 01 − 03 + 13 = ∂013
γ = 02 − 03 + 23 = ∂023
δ = ∂123 = α − β + γ.
```

These identities are proved from the actual simplicial boundary operators.
They do not assume a chain matrix or assert that a cap is present when its
boundary formula is written. For every ambient one-cycle `z`, the actual
vertex-boundary equations give the normal form

```text
z = z(12) • α + z(13) • β + z(23) • γ,
z(01) = z(12) + z(13).
```

For each grid point `p`, define the conditional coefficient functional on
actual one-cycles by `Fₚ(z) = z(01)` when `p ∈ {a,b,c}`, and `Fₚ(z) = 0`
otherwise. The raw edge coefficient is used only on the support; outside it,
`Fₚ` is the zero functional. Sublevel membership forces coefficients of
missing edges to vanish where the cycle argument needs that fact. The kernel
of this conditional functional is exactly the actual triangle-boundary
submodule at each of the nine grid points:

* At `o`, the one-skeleton has no one-cycles.
* At `a` and `b`, the supported one-cycle is respectively `α` or `β`, so the
  common-edge coefficient identifies the homology with `k`.
* At `c`, cycles have form `xα+yβ+zγ` and the coefficient is `x+y`. Its kernel
  is generated by the actual boundaries `γ` and `δ`; for `x+y=0`, a filling is
  `x[123] + (z-x)[023]`.
* At `d` and `e`, the actual cap `012` or `013` kills the sole cycle.
* At `f=(1,2)`, `g=(2,1)`, and `h=(2,2)`, the available triangle boundaries
  fill every one-cycle. At `f` and `h`, a filling is
  `(x+y)[012] - y[123] + (z+y)[023]`. At `g`, a filling is
  `(x+y)[013] + x[123] + (z-x)[023]`.

All these coefficient identities use only addition and subtraction. In
particular, the same proof covers characteristic two. The coefficient
functional is surjective on supported fibers by the actual cycles `α` or `β`.
Actual chain inclusions preserve ambient edge coefficients, and the conditional
cycle functional is natural for every comparable pair of grid points. Descending
that equality through the actual cycle/boundary quotients and the existing
homology-quotient naturality comparison gives a natural isomorphism
`finiteIso` from the grid restriction of actual simplicial homology to
`finiteModule`.

## Every real grade and finite presentation

The finite-coordinate restriction is proved to have exactly the pre-existing
grid `G`. The canonical finite-simplicial left Kan comparison identifies the
actual real-coordinate homology module with the left Kan extension of its grid
restriction, including grades below the grid and parameters between or above
grid values. Applying that comparison to `finiteIso` gives
`RankResolutionDegreeTwoSimplicial.realIso`:

```text
finiteSimplicialHomology k boundaryTetrahedronGrading 1
  ≅ RankResolutionDegreeTwo.realModule.
```

The original `GradedFree.FinitelyPresented.{u,0,0}` predicate for this actual
homology module follows directly from the existing finite-input homology
theorem; it is not an input witness. The separate examples module proves that
actual inclusion-induced maps `a → c` and `b → c` are nonzero, that the caps
kill the corresponding classes, and that the same statements hold at selected
real grades between grid values. It also proves that the actual homology is
zero below the grid.

The theory APIs live in `TDA.Persistence.RankResolutionDegreeTwoSimplicialFinite`
and `TDA.Persistence.RankResolutionDegreeTwoSimplicial`. The fixture module
`TDA.Persistence.RankResolutionDegreeTwoSimplicialExamples` contains the
concrete map consumers and the rational and `ZMod 2` ordinary-import examples.
This realizes the existing two-coordinate rank-relative degree-two witness;
it makes no claim about ordinary functor-category projective dimension of the
module, arbitrary-module realization, higher-dimensional sharpness, stability,
or acyclicity of the tetrahedron boundary.
