# Mathematical sources and conventions

These notes explain mathematical definitions, hypotheses, conventions and selected
comparisons with their sources. Use the [guide by subject](../README.md) to find a note,
the [API guide](../api.md) for declaration names and exact contracts, and the
[source register](references.md) for exact source versions, attribution, mappings and
use-specific rights evidence. This page follows the current checkout and may describe
unreleased work. For a published release, use the versioned release notes and API guide
linked from the [changelog](../../CHANGELOG.md).

## Maintaining the notes and sources

This directory holds durable, source-grounded mathematical definitions, statements,
conventions and bibliographic references as work is undertaken. Primary sources take
precedence over digests. No mathematical roadmap is prescribed by the scaffold:
dot manages the overall roadmap, milestones, priorities and progress in the private
[tda-lib Project](https://github.com/orgs/uda-lab/projects/5). GitHub Issues carry full
mathematical specifications, dependencies, acceptance conditions and execution contracts.
Project milestones are provisional; they do not prescribe serial execution, dates or
completion of all milestones for the first stable release.

[The source register](references.md) is the single bibliography for existing sources and
next directions. Its stable keys bind specific consulted manifestations, ordered authors,
printed affiliations, mathematical consumers and use-specific rights evidence. Explicit
unresolved fields are not verification claims; bibliography accuracy, mathematical fidelity
and legal-use permission are separate questions. Preserve useful mapping details and update
the same record when an edition is checked. Local source copies belong in gitignored
`sources/`; do not commit paper archives or investigation logs. Mathematical changes travel
through reviewed PRs, with fidelity evidence in their Issues and PRs.
