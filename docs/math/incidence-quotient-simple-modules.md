# Simple right modules over the diagonal quotient

Let `k` be a field and `S` a finite lattice. Put

`P = { (a,b) ∈ (WithTop S) × (WithTop S) | a ≤ b }`,

let `A = k[P]` be its incidence algebra, let `I` be the two-sided ideal generated by the
diagonal idempotents, and let `q : A → B = A/I` be the quotient map. Put `C = Bᵐᵒᵖ`. A strict
vertex is `v = (a,b) ∈ P` with `a < b`. Left `C`-modules are the actual right `B`-modules, in the
opposite-endomorphism convention used by `Hom(L, -)`.

The existing character `χ̄ᵥ : B →ₐ[k] k` is characterized by
`χ̄ᵥ(q(f)) = f(v,v)`. It defines a ring character on the right-module ring by
`χᵣᵥ(c) = χ̄ᵥ(unop c)`. This uses `RingHom.fromOpposite` and the commutativity of the field.
Let `Vᵥ` be the actual restriction of the field module along `χᵣᵥ`. It is a simple left
`C`-module, equivalently a simple right `B`-module.

For every simple `C`-module `M`, there is exactly one strict vertex `v` for which
`M ≅ Vᵥ` by a `C`-linear isomorphism. The statement imposes no finite-dimensionality,
eigenvector, or semisimplicity premise on `M`. The vertex is unique, but the isomorphism is
chosen from a nonzero generator and is not asserted to be canonical or unique. The useful
matrix-unit laws are public: with `dₚq = op(q(δₚq))`, the finite family satisfies
`∑ₚ dₚₚ = 1`, and `dₚq dᵣs` is zero unless `s = p`, when it equals `dᵣq`. On `Vᵥ`, `dₚq`
acts as the identity when `p = q = v` and as zero otherwise.
Thus `dᵥᵥ` distinguishes `Vᵥ` from every `V𝑤` for `w ≠ v`; consumers can use
`rightVertexModule_iso_iff` without unfolding the module construction.

The classification selects a maximal interval pair on which some diagonal idempotent acts
nontrivially. Diagonal pairs are killed in the quotient, so the selected pair is strict. The
opposite matrix-unit multiplication then forces every matrix unit to act on the selected vector
by its vertex character. Expanding a quotient element in the incidence-delta basis gives the
character eigenvector relation, and the map sending `t : k` to `t` applied to that vector is a
nonzero `C`-linear map from `Vᵥ`. Simplicity makes it an isomorphism. This proof is for the actual
opposite quotient and does not replace the quotient by a commutative action. The generated
linear map is explicitly `t ↦ algebraMap k C t • x`, with this formula exposed by
`rightVertexModuleGeneratedMap_apply`.

The linked functor `Fᵥ` is the existing character-coinvariant functor on left `A`-modules; in
`(Fᵥ.leftDerived 0).obj B`, `B` is the quotient regarded as a left `A`-module. Restricting the
`C`-linear classification isomorphism along `k → C`, identifying the restricted character
module with `k`, and composing with the canonical degree-zero comparison in
[the derived vertex calculation](incidence-vertex-tor.md) gives an isomorphism of underlying
`k`-modules with that derived value. This derived comparison is only `k`-linear; no `C`-action on
the derived object is asserted. The same classified vertex has zero left-derived value in every
positive degree by the existing results in that calculation. The Bool and singleton examples
instantiate these results over arbitrary fields, with `ℚ` as an explicit infinite field.

The source convention is consistent with [BOOS24-v3, §2.4](https://arxiv.org/html/2208.00300v3#S2.SS4),
which treats persistence modules as right modules. The simple-module classification is the
classification step used in [Lemma 5.7](https://arxiv.org/html/2208.00300v3#S5.SS1), in its
finite-poset quotient argument, specialized here to the interval-pair poset and its diagonal
ideal. This formalization proves that bounded classification step and the derived comparison;
it does not prove Lemma 5.7's global-dimension inequality, a global-dimension bound for `A`, or
the downstream numerical persistence bounds.
